# Telco Customer Churn Prediction

## Project Overview
This project predicts whether a telecom customer is likely to churn using Machine Learning.

## Dataset
- Dataset: Telco Customer Churn
- Total Records: 7043
- Features: 21

## Project Steps
- Data Loading
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Preprocessing
- Label Encoding
- Train-Test Split
- Random Forest Classifier
- Model Evaluation
- Feature Importance Analysis

## Model Performance
- Accuracy: 79.7%
- Algorithm: Random Forest Classifier

## Key Findings
- Tenure
- Monthly Charges
- Total Charges
- Contract Type

These are the most important factors affecting customer churn.
